After the database is up, create the schema once (and again after each upgrade, before starting
the new metadata service):

```sh
python -c 'from ebs.meta import migrations; migrations.upgrade("postgresql+psycopg://ebs:…@db.example:6432/ebs?sslmode=require")'
```
