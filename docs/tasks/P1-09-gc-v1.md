# P1-09 — Garbage collection v1 (access tracking, pins, leases, mark & sweep)

Status: todo · Phase: 1 · Depends on: P0-09, P0-10, P0-15 · Size: L

## Goal
Bounded CAS storage without ever deleting something a release, a pinned build or a running build needs.

## Read first
- docs/architecture.md § "Artifact storage and garbage collection" → Garbage collection 1–5
- docs/design/data-model.md Phase 1 tables; invariant I15

## Scope (files)
- create `src/ebs/gc/{roots,mark,sweep,quota,leases,report}.py`, `src/ebs/cli/gc.py` (`ebs gc [--dry-run]
  [--domain D]`, `ebs pin BUILD`, `ebs unpin BUILD`), Alembic revision for Phase 1 tables
- create `deploy/gc/ebs-gc.service` + `.timer` (nightly per domain)
- tests `tests/unit/gc/*`, `tests/integration/test_gc_concurrent_build.py`

## Requirements
- R1 Access tracking: cache hits, fetches, materializations and imports call `touch` (batched, throttled per
  P0-10 R3); the `blobs` table gains rows on every CAS put via the runner/driver.
- R2 Roots: release outputs (table exists from P2-02; until then empty), pinned builds (all their outputs +
  plan + logs), live leases (driver acquires a lease on plan inputs and outputs at build start and renews it
  on heartbeat; lease TTL 15 min).
- R3 Mark: closure over trees (a root tree marks all child manifests and blobs) and over action-cache entries
  whose outputs are marked.
- R4 Sweep order (I15): unreached action-cache rows unused for > `ttl_days` are deleted and tombstoned first;
  their blobs are deleted only after `grace_hours` (default 24) and only if still unreached and untouched.
- R5 Quota: above `high_water` × quota, LRU-evict unrooted objects until `low_water`; report what was evicted.
- R6 `--dry-run` produces the same report without deleting; the report shows reclaimable bytes per step,
  per project and per build.
- R7 GC runs as the service account with domain group membership, one domain per run, and is safe to run
  concurrently with builds (integration test: a build starts during sweep and its cache hits remain valid).
- R8 CAS `tmp/` older than 24 h is cleaned (P0-09 `cleanup_tmp`).
